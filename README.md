# voca.gg

실시간 1대1 영어 단어 대결 게임 - 토스 앱인토스 미니앱

## 게임 소개

첫 알파벳과 끝 알파벳이 주어지면, 5초 안에 조건에 맞는 영어 단어를 제시하는 실시간 대결 게임입니다.

## 현재 상태

[진행중] 1단계 기획 완료 - 2단계 설계 진행 예정

## 기술 스택

- React Native (Granite)
- Firebase Realtime Database + Firestore
- 앱 내장 단어 JSON DB
