# voca.gg - 화면 와이어프레임

## 1. 홈 화면

```
┌─────────────────────────┐
│         voca.gg         │
│                         │
│   [내 점수: 0]          │
│   [랭킹: -위]           │
│                         │
│  ┌─────────────────┐   │
│  │   대결 시작      │   │
│  └─────────────────┘   │
│                         │
│  ┌─────────────────┐   │
│  │   랭킹 보기      │   │
│  └─────────────────┘   │
└─────────────────────────┘
```

**컴포넌트:**
- 앱 타이틀
- 내 점수 / 현재 랭킹 요약
- 대결 시작 버튼 (primary)
- 랭킹 보기 버튼 (secondary)
