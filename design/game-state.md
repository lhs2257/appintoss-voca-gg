# voca.gg - 게임 상태 흐름

## 전체 상태 머신

```
[홈]
  │
  └─ 대결 시작 클릭
       │
       ▼
[매칭 대기]
  │  3초 내 상대 탐색
  ├─ 상대 발견 ──────────────────┐
  └─ 3초 초과 → 봇 매칭 ────────┤
                                  │
                                  ▼
                          [게임 시작]
                           라운드 1
                           조건 생성 (첫/끝 알파벳)
                           선공 랜덤 결정
                                  │
                                  ▼
                          [내 턴 / 상대 턴]
                           5초 타이머 시작
                                  │
                    ┌─────────────┴─────────────┐
                    │                           │
               [단어 입력]                 [5초 초과]
                    │                           │
          ┌─────────┴─────────┐                │
          │                   │                │
      [유효 단어]          [무효 단어]          │
          │                   │                │
     정답 처리            오답 처리         타임아웃
     애니메이션           표시                  │
     한국어 뜻                │                 │
     점수 획득               └────────┬─────────┘
          │                           │
          ▼                           ▼
    [턴 카운트 증가]           [패배 처리]
          │                           │
    turnCount < 5?                    │
          │                           │
     ┌────┴────┐                      │
    예          아니오                 │
     │          │                     │
     │     [라운드 종료]               │
     │      다음 라운드?               │
     │      새 조건 생성               │
     │      점수 배율 증가             │
     │          │                     │
  [턴 전환]     │                     │
  상대 턴 시작  └──────────────┐      │
                               │      │
                               ▼      ▼
                           [게임 종료]
                            결과 화면
                            점수 서버 저장
                            랭킹 갱신
```

---

## 턴 진행 상세

### 단어 유효성 검사 순서
1. 입력값이 빈 문자열인지 확인
2. 첫 알파벳 일치 여부 확인
3. 끝 알파벳 일치 여부 확인
4. 단어 DB에 존재하는 단어인지 확인
5. 같은 게임 내에서 이미 사용된 단어인지 확인

### 봇 턴 처리
- 봇은 단어 DB에서 조건에 맞는 단어를 랜덤으로 1개 선택
- 봇 응답 딜레이: 1.5초 ~ 3초 (랜덤, 자연스러운 느낌)
- 봇 난이도: v1에서는 단일 난이도 (항상 성공)

## Firebase 상태 동기화

```
플레이어A 입력 제출
  → Firebase /matches/{id}/currentTurn = "playerB"
  → Firebase /matches/{id}/words 배열에 추가
  → 플레이어B 실시간 감지 → 화면 업데이트

타이머는 클라이언트에서 각자 실행
  → 5초 초과 시 해당 플레이어가 /matches/{id}/status = "finished" 처리
  → 양측 결과 화면 진입
```
